# Shop

Первая версия интернет-магазина на ASP.NET Core MVC: каталог, корзина, заказы и панель администратора.

> Проект получил продолжение: актуальная версия с оптовыми ценами, пунктами самовывоза и юридическими документами находится в репозитории [WholesaleShop](https://github.com/TheFulum/WholesaleShop).

## О проекте

Интернет-магазин с базовой схемой e-commerce: товары, корзина, оформление заказа, личный кабинет покупателя и административная часть.

## Возможности

- Каталог товаров и страница товара с оценками покупателей.
- Корзина и оформление заказа, история заказов покупателя.
- Регистрация и вход, хеширование паролей.
- Панель администратора: товары, пользователи, заказы и их статусы.
- Отчёты по заказам с экспортом в Excel.

## Технологии

- C#, ASP.NET Core 8 MVC, Razor
- Entity Framework Core 8, MySQL
- BCrypt, ClosedXML, Chart.js
- Bootstrap

## Запуск

Нужны .NET 8 SDK и MySQL. Укажите пароль базы в `Shop/appsettings.json` вместо `YOUR_DB_PASSWORD`, примените миграции (`dotnet ef database update`) и запустите `dotnet run` из папки `Shop`.
